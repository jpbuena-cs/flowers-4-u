# Project notebook

This directory is the durable project memory. Update it when a design or technical decision changes so future work does not reopen settled questions without a reason.

## Reading order

1. [Design brief](./design-brief.md) — the intended experience and visual rules.
2. [Decisions](./decisions.md) — accepted constraints and the reasons behind them.
3. [Implementation plan](./implementation-plan.md) — architecture and next milestones.
4. [Progress](./progress.md) — what exists, what was checked, and open questions.

## Notebook rule

Keep the public-facing page free of copy and interface elements. Put explanations, TODOs, rationale, and development notes here or in the repository README instead.
